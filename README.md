# Pulse

**Pulse** (рабочее название) — Android-приложение, которое читает данные о здоровье
из [Health Connect](https://health.google/health-connect-android/) и считает по ним три показателя:

- **Recovery** — насколько организм восстановился (0–100 %);
- **Strain** — нагрузка за день (0–21);
- **Sleep** — качество и достаточность сна.

Своего браслета у приложения нет: подойдут любые часы или браслет, которые пишут данные
в Health Connect. «День» считается от пробуждения до следующего основного сна,
поэтому приложение подходит и тем, кто работает по ночам и спит днём.

> ⚠️ Это не медицинское устройство. Показатели — приблизительные оценки,
> они не заменяют консультацию врача.

**Приватность:** приложение не выходит в интернет, данные не покидают телефон.

## Состояние проекта

Сейчас **фаза 0**: настроена автоматическая сборка. Приложение показывает
экран-заглушку «Сборка работает». Дальше — главный экран, подключение Health Connect,
расчёт метрик, тренды и журнал.

## Как установить на телефон

1. Откройте на телефоне страницу **[Releases](https://github.com/argunov250-del/pulse/releases/latest)**.
2. В разделе **Assets** нажмите на файл `pulse-build-N.apk` — он скачается.
3. Откройте скачанный файл. Android спросит разрешение на установку из этого источника
   (браузера или «Файлов») — разрешите и нажмите **Установить**.
4. Если Play Защита предупредит о неизвестном приложении — выберите «Всё равно установить».

Требуется Android 9 или новее.

### Обновление

Скачайте более новый APK из Releases и установите поверх старого.

Если появляется ошибка **«Приложение не установлено»** — удалите старую версию и поставьте
новую заново. Так бывает, потому что пока сборки подписаны временным debug-ключом,
и он изредка меняется. Постоянная подпись появится позже.

## Как устроена сборка

Android Studio не нужна — APK собирается в облаке через GitHub Actions
(файл [`.github/workflows/build.yml`](.github/workflows/build.yml)):

- каждый **pull request** — проверочная сборка (APK лежит в артефактах запуска на вкладке Actions);
- каждое **слияние в `main`** — сборка и новый Release с тегом `build-N`, где N — номер сборки.

## Для разработчиков

```bash
./gradlew assembleDebug
```

Стек: Kotlin, Jetpack Compose, Material 3; minSdk 28.
В репозитории нет ключей, паролей и keystore — и не должно быть.
